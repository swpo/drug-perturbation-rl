# Open-source release checklist

This repository is being assembled and reviewed locally before any public remote
is created.

- [ ] Choose and add the code license.
- [ ] Confirm processed-data redistribution and required attribution.
- [ ] Review every tracked file for secrets, private URLs, and unrelated work.
- [ ] Replace or clearly label historical account-, checkpoint-, and run-specific
      configuration fields.
- [ ] Add a concise public results summary and only the figures needed to support
      it.
- [ ] Run the complete offline test suite from a clean environment.
- [ ] Build and inspect the wheel contents.
- [ ] Confirm the repository contains no private reports or operational memory.
- [ ] Create the GitHub repository only after the preceding checks pass.
